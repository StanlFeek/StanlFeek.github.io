# 淮北市实验高级中学 · 体育课选课系统

一个零第三方依赖的体育课选课网站：学生登录选课，管理员在后台生成账号、管理课程并查看选课情况。
只需要安装了 Node.js（v18 及以上即可）就能直接运行，无需 `npm install`、无需联网。

## 如何运行

```bash
node server.js
```

启动后浏览器访问：

| 页面 | 地址 |
| --- | --- |
| 学生登录页 | http://localhost:3000/ |
| 管理员后台 | http://localhost:3000/admin |

> 管理员入口的两种进入方式：
> 1. 在学生登录页**右下角**点击「⚙ 管理员入口」按钮；
> 2. 直接在浏览器地址栏输入 `http://localhost:3000/admin`。

## 默认账号

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | admin | password123456 |
| 演示学生 | demo | 123456（可在后台删除） |

> 首次启动会自动生成以上账号及 4 门示例课程（篮球 / 足球 / 羽毛球 / 乒乓球）。
> 管理员密码可在后台「系统设置」中修改；忘记密码时执行 `node server.js reset-admin` 恢复为默认值。

## 管理员生成学生账号的两种方式

### 1. 手动输入
登录后台 → 「用户管理」→「手动添加账号」，输入用户名和密码后点「添加账号」。

### 2. 批量导入（.txt 文本文档 / .xlsx 表格）
登录后台 → 「用户管理」→「批量导入账号」→ 选择本地文件（.txt 或 .xlsx）→ 点「上传并导入」。

**.txt 支持以下写法**（不同账号之间用 `；`、`;` 或换行隔开；同一行连续多条用逗号隔开也会自动识别）：

```
张三：123456；李四：abcdef
用户名:u001,密码:p123；用户名:u002,密码:p456
姓名：王小明,身份证：360323199001012345
```

**.xlsx 表格**：自动识别“用户名/账号/姓名、密码、身份证”所在列；没有表头时，会按“一列姓名/用户名 + 一列身份证号”的常见习惯自动判断。

**姓名 + 身份证 的处理规则**（txt 与 xlsx 一致）：
- 用户名取“姓名”；
- 密码取身份证号（自动忽略其中的空格）的**后 6 位**；
- 若同时提供了“用户名/账号”，用户名优先取它；
- 若提供了显式“密码”，密码优先取显式值。

兼容说明：
- 支持全角/半角冒号、逗号、分号；
- 标签可识别：`用户名` `账号` `姓名` `身份证/身份证号` `密码/口令` 等；
- 身份证列请使用“文本”格式保存，避免 Excel 自动把长数字变成科学计数法；
- 无标签的旧格式 `用户名:密码` 仍然支持；
- 密码中请勿包含 `；` `;` 或换行符；重复的用户名会自动跳过并在导入结果中提示。

## 学生端功能

- 用管理员发放的账号密码登录；
- 每人限选 1 门体育课，可查看课程人数、改选或取消；
- 课程名额已满时不可再选。

## 管理员后台功能

- 用户管理：手动添加 / 批量导入 / 搜索 / 重置密码 / 删除账号；
- 课程管理：添加课程（名称、教师、地点、人数上限）、删除课程（同时清除该课程选课记录）；
- 选课情况：查看各课程人数与每名学生的选课明细，可导出 CSV；
- 系统设置：修改管理员密码、下载数据备份。

## 常见问题

- **改端口**：`PORT=8080 node server.js`（Windows PowerShell 可用 `$env:PORT=8080; node server.js`）。
- **仅本机访问**：`HOST=127.0.0.1 node server.js`；默认 `0.0.0.0`，局域网内其他电脑可用 `http://本机IP:3000` 访问。
- **数据存在哪里**：所有账号、课程、选课记录保存在项目目录下的 `data.json`（首次启动自动生成）。需要备份时可在后台「系统设置」下载，或直接复制 `data.json`。
- **重置管理员密码**：`node server.js reset-admin`（密码恢复为 `password123456`）。

## 技术说明

- 纯 Node.js 内置模块实现 HTTP 服务，无任何第三方依赖；
- 学生密码使用 scrypt 加盐哈希存储，不保存明文；
- 登录会话使用 HttpOnly Cookie；
- 批量导入兼容 UTF-8 与 GBK/GB18030 编码的文本文件。

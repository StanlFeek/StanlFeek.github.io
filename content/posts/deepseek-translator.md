Google 翻译看技术文章不太行，商店里的插件要么收费，要么翻译效果一般。我干脆用 DeepSeek API 写了个 Chrome 扩展。

## 目前支持

- 划词翻译
- 整页翻译
- 恢复原文
- 弹窗快速翻译
- 右键菜单
- 快捷键 `Alt + Shift + T`

## 隐私与翻译策略

API Key 只保存在浏览器本地，不会上传到 GitHub。

整页翻译会跳过代码块、输入框、隐藏区域和插件自己的界面，并分批发送给 DeepSeek，避免一次性塞太多内容。

## 安装方法

1. 打开 `chrome://extensions/`
2. 开启“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择 `deepseek-translator` 文件夹
5. 在设置里填写 DeepSeek API Key

## 已知限制

目前动态加载的新内容不会自动翻译，复杂的在线文档也可能需要手动划词。

不过日常看博客、新闻和技术文档已经够用了。

## 更新日志

### v1.1.0 · 2026-09-24

**给 DeepSeek 翻译插件加上了实时翻译**

版本：`1.1.0`\
日期：2026-09-24

之前插件只能手动点击“翻译整个网页”。遇到评论、搜索结果这类不断加载内容的页面，每次都要重新点一次，有点麻烦。

这次在扩展弹窗底部加了一个“实时翻译”开关。

开启后，插件会自动翻译当前页面，并继续处理网页后续新增的文字。关闭后会停止监听，并把之前翻译的内容恢复成原文。开关状态保存在浏览器本地，重新打开弹窗后仍会保留。

另外做了一些细节调整：

- 已经翻译过的文字不会重复发送给 API
- 网页在翻译过程中更新文字时，不会覆盖网页的最新内容
- 恢复原文时同步清理翻译记录
- 中英文 README 补充了实时翻译说明和 API 用量提示

需要注意，实时翻译开启后，网页新增内容会持续调用 DeepSeek API，因此用量和费用会比手动翻译更高。不用时建议及时关闭。

已经使用旧版本的话，在 `chrome://extensions/` 里点击“重新加载”，刷新网页即可看到新开关。
